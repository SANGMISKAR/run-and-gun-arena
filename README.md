# Run & Gun Arena

A small, original browser game prototype inspired by the classic run-and-gun arcade genre.

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Features

- Three selectable missions with distinct arenas and final bosses
- Grunts, jumpers, and ranged enemies
- Spread-shot and rapid-fire power-ups
- Original Web Audio shooting, jump, hit, and boss cues
- Touch controls on small screens

## Controls

- **A / D** or **Arrow keys**: move
- **W / Space**: jump
- **J / Z**: fire
- **Enter**: return to mission select after game over

The game uses original canvas shapes and does not include copyrighted game art, characters, music, or level data.
